No current Magistrala service publishes events to Redis Streams. The `users`, `clients`, and `bootstrap` services that once did are now consolidated into **Atom** (`bootstrap` is now `atom-bootstrap`) — see [Entities](/dev-guide/entities) and [Architecture](/dev-guide/architecture) for the current service model. The standalone `mqtt` adapter that also published to Redis Streams no longer exists either; MQTT protocol handling is absorbed into FluxMQ natively. The Go package this mechanism used to be implemented in, `pkg/messaging/events`, has no importers anywhere in the current codebase.

For tracking entity, channel, and group activity today — creation, updates, disabling, connectivity, role changes — see [Entities § Audit logs](/dev-guide/entities#audit-logs), which covers Atom's own audit log.
