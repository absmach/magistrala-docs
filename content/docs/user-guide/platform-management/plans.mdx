This page applies to Magistrala Cloud only. Self-hosted (Enterprise Edition) deployments don't
have a Billing Plans tab under Platform Management.
</Callout>

## Overview

The **Plans** tab under **Platform Management** lets a platform administrator define and manage the billing plans workspaces can subscribe to. This is distinct from a workspace's own [Billing page](/user-guide/workspace-management/billing), where a workspace member subscribes to one of these plans — here, an administrator defines what plans exist in the first place.

To access it, go to **Platform Management** in the sidebar, then select the **Plans** tab.

![Plans Table](../../img/platform-management/plans-table.png)

## Create a plan

Click **+ Create** to open the create-plan form.

|Property |Description| Required |
|-----------------|------------------------------------------|----------|
|Name |The plan's display name| ✅ |
|Description |A short description of the plan| Optional |
|Amount |The plan's price| ✅ |
|Public Plan |Whether any workspace can subscribe, or only specific ones| ✅ |
|Allowed Workspaces |Restrict the plan to specific workspaces (only shown if Public Plan is off)| Conditional |
|Limits |JSON object defining the plan's resource limits| Optional |
|Metadata |Custom JSON metadata| Optional |

![Create Plan](../../img/platform-management/create-plan.png)

## Manage a plan

Click a row to open a plan's detail page, or use the row actions to:

- **Enable/Disable** the plan — a disabled plan can no longer be subscribed to
- **Set as Default** — the plan new workspaces are subscribed to automatically
